Catálogo Sou Bela pronto para GitHub Pages

Arquivos:
- index.html
- logo.png
- imagens/
- downloads/

Como publicar:
1. Crie um repositório público no GitHub.
2. Envie todos estes arquivos para a raiz do repositório.
3. Em Settings > Pages, selecione Branch: main e folder: /root.
4. Salve e aguarde o link do GitHub Pages.

Observação:
- Os botões de baixar já apontam para zips prontos em downloads/.
